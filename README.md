# Sargam Chourasia - React Portfolio

Responsive personal portfolio built with React + Vite.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address shown by Vite.

## Production build
Run `npm run build`.

## Data note
Profile details were taken from the supplied LinkedIn screenshots and known project context. Sections not visible in the screenshots were not invented.
